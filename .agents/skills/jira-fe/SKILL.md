# K-Bap FE — Jira 상태 갱신 (범위 제한 자율)

> 이 세션(kbap-fe)은 **구현 담당**이다. Jira 쓰기는 아래 **좁은 범위만** 허용된다.
> 완료 판정·구조 변경은 리뷰어(예진 + spec 레포 메인 세션)가 한다. 안전 크리티컬(false-safe=0)이라 자기인증 완료는 금지.

## 접속
- 사이트 `simhani1.atlassian.net` · **cloudId `50957656-c97c-4cc0-b1ca-f209cef7d5c9`** · 프로젝트 **KB**.
- 도구(필요 시 ToolSearch로 로드): `mcp__atlassian__transitionJiraIssue`, `mcp__atlassian__addCommentToJiraIssue`, `mcp__atlassian__getTransitionsForJiraIssue`.
- FE 담당 accountId(참고): 김예진 `6275ff7c7de1ec00695c019e`.

## ✅ 허용 (자기가 작업 중인 이슈에 한해)
1. **상태 전환** — `transitionJiraIssue`:
   - 착수할 때: `할 일 → 진행 중` (전환 id **`21`**)
   - 작업 끝났다고 판단되면: `진행 중 → 검토 중` (전환 id **`31`**) ← **여기까지가 끝. 완료 아님.**
2. **진행로그 댓글** — `addCommentToJiraIssue` (아래 형식):
   ```
   <YYYY-MM-DD>

   진행한 것
   * <오늘 처리한 것 (커밋 해시 있으면 함께)>

   블락된 것
   * <막힌 것 / 없으면 "없음">

   진행할 것
   * <다음 단계 / 없으면 "없음">
   ```
   - 날짜는 **실제 `date '+%Y-%m-%d'` 출력** 사용(추측 금지).
   - 언제: 이슈 완료(검토중 전환) 시 · 하루 작업 마칠 때 · 막혔을 때.

## ⛔ 금지 (리뷰어 전담 — 절대 하지 말 것)
- **`완료` 전환 금지** (전환 id 41). 검토 중까지만. 완료는 리뷰 후 메인 세션이.
- **BE-논의 플래그 설정 금지.** 대신 논의/공유 필요하면 **진행로그 댓글에 "BE 논의 필요: …" 한 줄** 남기고, 리뷰어가 플래그를 건다.
- **이슈 생성 금지 · 에픽(parent)/라벨/summary/description 수정 금지.** 구조 변경은 리뷰어.
- 남의 이슈(자기가 작업하지 않은 것) 건드리지 말 것.

## 절차
1. 착수: 대상 KB 이슈 확인 → `진행 중`(21).
2. 완료 판단: `검토 중`(31) 전환 + 진행로그 댓글. (BE 논의 필요하면 댓글에 명시.)
3. 그 다음은 리뷰어가 코드/DoD 확인 후 완료 처리. 되돌려지면 다시 진행 중으로.

## 원칙
- 자율의 범위 = **진행중·검토중 전환 + 진행로그 댓글**, 그 이상은 리뷰어.
- Jira를 코드보다 뒤처지게 두지 말 것 — 커밋 시점에 바로 상태·댓글 반영(그게 이 자율권의 목적).
